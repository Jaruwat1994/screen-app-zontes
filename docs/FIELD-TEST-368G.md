# ทดสอบภาคสนาม Zontes 368G (F2)

ทดสอบ ZRide Screen กับรถจริงก่อนแจกผู้ใช้ไทยกลุ่มแรก แต่ละรอบให้กรอกตารางข้อมูลเครื่องหนึ่งแถว และผลทดสอบหนึ่งชุด แล้วแนบ log จาก **ความช่วยเหลือ → รายงานปัญหา**

## ข้อมูลเครื่อง (กรอกทุกรอบ)

| วันที่ | รุ่นรถ / ปี | firmware หน้าปัด | มือถือ / Android | Android Auto | ZRide Screen (เวอร์ชัน + git) |
| --- | --- | --- | --- | --- | --- |
|  | 368G |  |  |  |  |

firmware หน้าปัด: ดูจากเมนูตั้งค่าบนหน้าปัด หรือบรรทัด `CLIENT_INFO` ใน log

## รายการทดสอบ

| # | เรื่อง | ทำอย่างไร | ผ่านเมื่อ | ผล |
| --- | --- | --- | --- | --- |
| 1 | เชื่อมต่อครั้งแรก | สแกน QR บนหน้าปัด → เชื่อมต่อ | ภาพขึ้นหน้าปัดภายใน 30 วินาที |  |
| 2 | เชื่อมต่อซ้ำ | ดับเครื่อง 1 นาที → ติดเครื่อง → กด เชื่อมต่อ | ต่อกลับเองโดยไม่ต้องสแกนใหม่ |  |
| 3 | จอ 1024×425 | Android Auto: Maps / Waze | ไม่มีขอบตัด ภาพไม่ยืด ปุ่ม AA อยู่ในจอ |  |
| 4 | หน้าปัดกำหนดเอง | ลอง template ทั้ง 9 แบบ | ตัวอักษรไม่ซ้อน อ่านได้ตอนขี่ ภาษาไทยไม่ล้น |  |
| 5 | นาฬิกาหน้าปัด | ดูเวลาบนหน้าปัดหลังเชื่อมต่อ | ตรงกับมือถือ ±1 นาที |  |
| 6 | ปุ่มที่แฮนด์ | กด ขึ้น / ลง / เลือก / ย้อนกลับ | ทุกปุ่มทำงานใน AA และหน้าปัดกำหนดเอง |  |
| 7 | จอดับ / ติดไฟแดง | จอด 3 นาที ปล่อยหน้าปัดดับเอง | กลับมาเองเมื่อหน้าปัดติด หรือกด เชื่อมต่อ ครั้งเดียว |  |
| 8 | ขี่ต่อเนื่อง | ขี่ 30 นาทีกลางแดด | ภาพไม่ค้างเกิน 2 วินาที, มือถือไม่ร้อนจนแอปเตือน |  |
| 9 | ตรวจจับการล้ม (จำลอง) | ตั้งค่า → ตรวจจับการล้ม → ทดสอบ | หน้าแจ้งเตือนขึ้น, ปุ่ม "โทร 1669" เปิดหน้าโทร, ข้อความ SMS เป็นภาษาไทย |  |
| 10 | ลูกระนาด / หลุม | ขี่ผ่านลูกระนาด 10 ครั้ง แล้วจอดติดไฟแดง | ไม่มีการแจ้งเตือนล้ม |  |
| 11 | น้ำมัน | เปิด ปั๊มน้ำมันใกล้เคียง | มีปั๊มใกล้ ๆ และราคาแก๊สโซฮอล์ 95 ของวันนี้ |  |
| 12 | ส่ง log | ความช่วยเหลือ → รายงานปัญหา → LINE | ได้ไฟล์ .txt ไม่มีเบอร์โทร พิกัด หรือรหัส Wi‑Fi |  |

## KPI ตั้งต้น (baseline)

| ค่าที่วัด | วิธีวัด | ผล |
| --- | --- | --- |
| เวลาเชื่อมต่อครั้งแรก (วินาที) | จับเวลาจากกด เชื่อมต่อ ถึงภาพขึ้น |  |
| เวลาเชื่อมต่อซ้ำ (วินาที) | เหมือนข้อ 2 |  |
| ภาพหลุดต่อชั่วโมง (ครั้ง) | นับระหว่างข้อ 8 |  |
| อุณหภูมิมือถือสูงสุด (°C) | หน้าปัด Pro แสดงอยู่มุมซ้าย |  |
| แจ้งล้มผิด (ครั้ง / 100 km) | นับระหว่างขี่ทั้งหมด |  |

ถ้าข้อใดไม่ผ่าน ให้กด รายงานปัญหา ทันทีหลังเกิดเหตุ (log ช่วงท้ายสำคัญที่สุด) แล้วจดเลขข้อไว้ในช่องปัญหา
